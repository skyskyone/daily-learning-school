# 靈樹階段圖片路徑

把你自己的透明背景 PNG 插畫上傳到此資料夾，檔名請與下列路徑一致。圖片會自動依學生的靈樹階段切換。

1. `stage-01-land.png` — 一方靈土／小山丘
2. `stage-02-seed.png` — 靈種入土
3. `stage-03-sprout.png` — 破土萌芽
4. `stage-04-two-leaves.png` — 初展雙葉
5. `stage-05-seedling.png` — 幼苗初立
6. `stage-06-young-tree.png` — 小樹成形
7. `stage-07-growing-tree.png` — 青木舒枝
8. `stage-08-mature-tree.png` — 蒼樹成蔭
9. `stage-09-world-tree.png` — 世界樹

建議：每張圖片使用相同畫布比例（例如 1000 × 700），以透明背景 PNG 為佳，樹或山丘主體置中、底部對齊。未上傳圖片時，網站會顯示內建的 CSS 水墨風示意圖，不會出現破圖圖示。

實際路徑：`assets/world-tree/<上述檔名>`


## 太陽與月亮圖示

把自製圖片上傳到同一資料夾：

- `sun.png` — 路徑：`assets/world-tree/sun.png`
- `moon.png` — 路徑：`assets/world-tree/moon.png`

規格建議：透明背景 PNG，正方形畫布 256 × 256 px（最低 128 × 128 px）；主體置中並保留約 10% 四周空白。太陽建議使用金色、朱紅或水墨金輪；月亮建議用淡銀藍／灰白新月，兩張圖需有一致的中國傳統插畫或工筆風格。避免圖片內包含文字，因為它們會縮放成樹景角落的小圖示。未上傳或圖片無法讀取時，網頁會自動退回文字日月符號。

## 金色果實

- 路徑：`assets/world-tree/fruit-gold.png`
- 規格建議：透明背景 PNG，畫布 256 × 320 px（最低 128 × 160 px）；單顆金色果實置中，附短果梗，外圍保留約 8–12% 透明邊界。建議使用琥珀金、淡金高光和深金陰影，不要加背景、枝葉或文字。

到達第九階後，每顆新果實都會建立獨立的圖片元素並定位在樹冠上；兩日後轉到地面果實區，原本果實圖片規格會重複使用。若未上傳果實圖片，網頁仍會以金色小果實形狀顯示。

目前樹上預設位置在 `world-tree.js` 的 `HANG_POSITIONS` 陣列中；你可以改動每顆果實的左右與上下百分比。落地果實位置由 `renderFruits()` 的位置計算產生，會隨數量逐顆增加。
