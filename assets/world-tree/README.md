# 靈樹八階圖片路徑

網站目前採用 **八階成長**，以每階段的圖片顯示學生養成進度。為了沿用已上傳的九階舊圖，不必重新上傳：

1. 第 1 階「一方靈土」：`stage-01-land.png`
2. 第 2 階「靈種入土」：`stage-02-seed.png`
3. 第 3 階「破土萌芽」：`stage-03-sprout.png`
4. 第 4 階「初展雙葉」：`stage-04-two-leaves.png`
5. 第 5 階「幼苗初立」：`stage-05-seedling.png`
6. 第 6 階「小樹成形」：`stage-06-young-tree.png`
7. 第 7 階「蒼樹成蔭」：`stage-08-mature-tree.png`
8. 第 8 階「世界樹」：`stage-09-world-tree.png`

實際路徑：`assets/world-tree/<檔名>`。

舊版的 `stage-07-growing-tree.png` 暫時不會被網站使用，但可以保留在 GitHub，不必刪除。若要重新製作八階圖片，請參考 [靈樹八階圖片提示詞](world-tree-8-stage-prompts.md)。

建議圖片使用相同尺寸及比例（例如 1536 × 864、16:9 橫向 PNG），樹幹／小芽中心固定於畫面中線，樹根或土地接觸基線保持一致。網站會自動按圖片尺寸調整容器比例；若圖片無法載入，會使用內建 CSS 樹形作為備用顯示。

## 太陽與月亮圖示

把自製圖片上傳到同一資料夾：

- `sun.png` — 路徑：`assets/world-tree/sun.png`
- `moon.png` — 路徑：`assets/world-tree/moon.png`

規格建議：透明背景 PNG，正方形畫布 256 × 256 px（最低 128 × 128 px）；主體置中並保留約 10% 四周空白。太陽建議使用金色、朱紅或水墨金輪；月亮建議用淡銀藍／灰白新月，兩張圖需有一致的中國傳統插畫或工筆風格。避免圖片內包含文字，因為它們會縮放成樹景角落的小圖示。未上傳或圖片無法讀取時，網頁會自動退回文字日月符號。

## 金色果實

- 路徑：`assets/world-tree/fruit-gold.png`
- 規格建議：透明背景 PNG，畫布 256 × 320 px（最低 128 × 160 px）；單顆金色果實置中，附短果梗，外圍保留約 8–12% 透明邊界。建議使用琥珀金、淡金高光和深金陰影，不要加背景、枝葉或文字。

到達第八階後，每顆新果實都會建立獨立的圖片元素並定位在樹冠上；兩日後轉到地面果實區，原本果實圖片規格會重複使用。若未上傳果實圖片，網頁仍會以金色小果實形狀顯示。

目前樹上預設位置在 `world-tree.js` 的 `HANG_POSITIONS` 陣列中；你可以改動每顆果實的左右與上下百分比。落地果實位置由 `renderFruits()` 的位置計算產生，會隨數量逐顆增加。

## 上傳圖片後的自動尺寸調整

靈樹頁面會讀取目前階段圖片的實際寬度與高度，並自動調整圖片容器比例；舊有的內框、陰影邊框與圖片兩側多出的留白已移除。太陽與月亮會定位在圖片本身的左上角、右上角區域，而不是定位在外層面板。

建議仍統一使用 16:9 橫向 PNG（例如 1536 × 864），九個階段的樹根接地位置一致，切換時最自然。若上傳不同比例的圖片，畫面會跟著該圖片比例調整；為了九階成長觀感一致，建議八張圖使用同一尺寸與比例。
